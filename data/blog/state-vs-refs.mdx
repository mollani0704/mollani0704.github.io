## state는 "UI 상태"를 저장하는 것

state는 **화면에 영향을 주는 데이터**를 저장하는 데 사용한다.

예를 들어:

- 카운트 숫자
- 입력창 값
- 모달 열림 여부
- 로그인 여부

같이 **UI에 직접 영향을 주는 값**이다.

예제:

```jsx
import { useState } from 'react'

function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>{count}</p>
      <button onClick={() => setCount(count + 1)}>증가</button>
    </div>
  )
}
```

여기서

```jsx
setCount(count + 1)
```

이 실행되면

1. state가 변경됨
2. React가 다시 렌더링함
3. UI가 업데이트됨

즉

**state는 UI를 업데이트하기 위한 데이터다.**

## 2. ref는 "값을 기억하는 상자" 같은 것

ref는 값을 저장하지만 **렌더링을 발생시키지 않는다.**

예제:

```jsx
import { useRef } from 'react'

function Example() {
  const countRef = useRef(0)

  const increase = () => {
    countRef.current += 1
    console.log(countRef.current)
  }

  return <button onClick={increase}>증가</button>
}
```

여기서

```jsx
countRef.current
```

값이 바뀌어도

👉 **React는 렌더링하지 않는다.**

그래서 ref는 보통 이런 용도로 사용한다.

- DOM 접근
- 이전 값 저장
- 타이머 ID 저장
- 렌더링과 상관없는 데이터 저장

## 3. 가장 큰 차이 (핵심)

|             | state        | ref                |
| ----------- | ------------ | ------------------ |
| 값 변경     | setState     | ref.current        |
| 렌더링 발생 | ✅ 발생      | ❌ 발생 안함       |
| 주 용도     | UI 상태 관리 | DOM 접근 / 값 저장 |
| React 관리  | React가 추적 | 단순 객체          |

## 4. DOM 접근할 때 ref 사용

ref의 대표적인 사용 예는 **DOM 접근**이다.

예:

```jsx
import { useRef } from 'react'

function InputFocus() {
  const inputRef = useRef(null)

  const focusInput = () => {
    inputRef.current.focus()
  }

  return (
    <>
      <input ref={inputRef} />
      <button onClick={focusInput}>포커스</button>
    </>
  )
}
```

여기서

```jsx
inputRef.current
```

는 실제 DOM이다.

그래서

```jsx
inputRef.current.focus()
```

같은 작업이 가능하다.

## 5. 이전 값 저장할 때 ref 사용

state는 값이 바뀌면 렌더링이 발생하기 때문에

**이전 값을 저장할 때 ref를 많이 사용한다.**

예:

```jsx
const prevValue = useRef()

useEffect(() => {
  prevValue.current = value
}, [value])
```

이렇게 하면

```jsx
prevValue.current
```

에 이전 값이 저장된다.

렌더링도 발생하지 않는다.

## 6. 언제 state를 쓰고 언제 ref를 쓰는가

이 기준 하나만 기억하면 된다.

### state

👉 **UI에 영향을 주는 값**

예

- 카운트
- 모달 열림 여부
- 리스트 데이터
- 입력값

---

### ref

👉 **렌더링과 상관없는 값**

예

- DOM 요소
- 타이머 ID
- 이전 값
- mutable 값 저장

## 7. state 대신 ref 쓰면 안 되는 이유

가끔 이렇게 하는 사람이 있다.

```jsx
const countRef = useRef(0)

countRef.current += 1
```

이렇게 하면

👉 **화면이 업데이트되지 않는다.**

그래서 UI 상태는 반드시 **state를 사용해야 한다.**

## 8. 한 문장 정리

React에서

> **state는 UI 상태를 관리하기 위한 것이고, ref는 렌더링과 상관없는 값을 저장하기 위한 것이다.**
